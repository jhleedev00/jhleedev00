## About

국립한국교통대학교 전자공학과를 졸업했으며, 로봇 제어·임베디드 펌웨어·Edge AI 프로젝트를 수행했습니다.

- **Robot Control** — LiDAR 기반 도크 위치 추정, ICP 정합, PID·상태 머신 기반 정밀 도킹
- **Embedded Firmware** — STM32·AVR 센서 입력, 모터 제어, CAN·UART 장치 연동
- **Edge AI** — YOLO 학습, 객체·지형 인식, 공유 메모리 기반 병렬 추론
- **Hardware Integration** — 회로·PCB 설계부터 펌웨어 연동과 장비 동작 검증까지
